YouTube Audio Downloader

Paste a YouTube URL to extract and download the audio track.

YouTube Bot Detection Triggered
YouTube is blocking server-side requests. To fix this, add your YouTube cookies to the app:
  1. Install the "Get cookies.txt LOCALLY" extension in Chrome
  2. Go to youtube.com while logged in
  3. Click the extension and export cookies as Netscape format
  4. Go to Vercel Dashboard → Environment Variables
  5. Add variable: Key = YOUTUBE_COOKIES, Value = paste cookie file contents
  6. Redeploy the app
