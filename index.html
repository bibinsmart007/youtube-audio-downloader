⚠ YouTube Bot Detection Triggered

YouTube is blocking anonymous requests. Fix it by supplying your own cookies:

  1. Install the "Get cookies.txt LOCALLY" extension in Chrome/Firefox.
  2. Go to youtube.com while logged into your Google account.
  3. Click the extension icon and export cookies as Netscape format.
  4. Go to your Vercel Dashboard → Project → Settings → Environment Variables.
  5. Add: Key = YOUTUBE_COOKIES, Value = paste the full cookie file contents.
  6. Click Save, then go to Deployments and redeploy the latest build.
